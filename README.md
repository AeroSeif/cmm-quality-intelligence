## 1. Background and Motivation

While working as an **Overhaul Manufacturing Engineer at the Arab Organization for Industrialization (AOI)**, I realised that we needed to improve our measurement repeatability capabilities and make better use of the inspection data generated by our CMM processes.

A significant part of this was being able to assess measurement consistency, identify characteristics approaching their allowable limits, and make inspection results easier to review. Having this information organised and analysed properly can reduce manual work and help engineers identify potential issues more efficiently.

This project grew out of that requirement.

The implementation used within AOI is separate from the application presented in this repository. The internal version was authorised by the Operations Manager and integrated with the organisation's internal database.

**This repository contains a separate demonstration version**, developed using Python and Streamlit to demonstrate the functionality and engineering approach. It does not contain the internal application, database or production data.

The intention is straightforward: make CMM inspection data easier to work with, rather than having engineers manually review multiple inspection reports and calculate the relevant statistics themselves.

## 3. Application Overview

The application accepts multiple Excel inspection workbooks, extracts the measurement records, performs data validation and presents the results through an interactive dashboard.

It currently supports two separate study types.

### 3.1 Dynamic Repeatability

This study deals with repeated measurements of the **same physical component**.

Multiple inspection workbooks are processed and the dimensional measurements are grouped by characteristic.

The application calculates:

| Metric | Description |
|---|---|
| Mean | Average measured value |
| Standard deviation | Sample standard deviation of repeated measurements |
| Observed range | Difference between maximum and minimum readings |
| Study variation | Six-standard-deviation variation (6s) |
| Repeatability (%) | Study variation expressed as a percentage of total tolerance |
| Limit utilisation (%) | Repeatability percentage relative to the applicable acceptance limit |

Results are presented through a colour-coded dashboard, making it easier to identify characteristics approaching or exceeding their applicable repeatability limits.

The current demonstration uses the following configurable classification limits:

| Classification | Repeatability limit |
|---|---:|
| Critical | 10% |
| Major | 20% |
| Minor | 30% |

These values must be verified against the applicable customer requirements and approved standard revision before engineering use.
